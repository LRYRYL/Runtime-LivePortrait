# portraits/ — 底图说明

## 图片从哪来

| 文件 | 来源 |
|---|---|
| `sample.jpg` | **StyleGAN2-FFHQ 生成，不是真人**（seed 117，truncation ψ=0.55）—— 女性 |
| `sample2.jpg` | **StyleGAN2-FFHQ 生成，不是真人**（seed 6，truncation ψ=0.55）—— 男性 |
| `sample3.PNG` | AI 生成的插画角色（非真人）|
| `my_face.jpg` / `my_face.png` | 你自己放的（可选，网页里上传也会存成 `uploaded.*`）|

**网页的默认底图是 `sample.jpg`**。其他样张在页面左侧的「内置样张」下拉框里选，
不用手动传文件。

## 关闭时哪些文件会被保留

**规则是模式，不是名单**：凡是**图片**且文件名叫 **`sample*`** 的都会保留，
所以再放 `sample4.png` 也**不需要改代码**。

| 文件 | 关闭时 |
|---|---|
| `sample.jpg` / `sample2.jpg` / `sample3.PNG` / `sample4.*` … | **保留** |
| `uploaded.*`（网页上传）| 删除 |
| `my_face.*` 等你手动放的其它照片 | 删除 |
| 非图片（`notes.md`、`data.json`…）| **不受影响**（清理只针对图片）|

判定是**大小写不敏感**的，`sample3.PNG` 和 `sample3.png` 一样保留。

## 为什么用合成脸而不是真人照片

之前这里放的是真人照片（先是汤姆·克鲁斯，后是你的照片）。
换成合成脸是为了**彻底避免权利问题**：

- 合成脸**不对应任何真实的人** → 没有肖像权、没有本人授权问题
- 单人照片来自 FFHQ 数据集（`CC BY-NC-SA 4.0`，**仅限非商业**）
- 而同是这个数据集的镜像数据集 **SFHQ** 明确写明：
  > "all images in this dataset are synthetically generated so there are no privacy
  > issues or license issues surrounding these images"
  >
  > —— [SelfishGene/SFHQ-dataset](https://github.com/SelfishGene/SFHQ-dataset)

合成脸在这一点上比数据集里的真人照片更干净，而且**可复现**——
不需要下载任何数据集，用本机已有的权重就能重新生成。

## 两张样张的质量（实测）

**sample.jpg（女性, seed 117）**

| 指标 | 值 | 含义 |
|---|---|---|
| yaw | **-0.87°** | 几乎完全正脸 |
| pitch | **+0.72°** | 几乎无俯仰 |
| roll | **-0.90°** | 几乎不歪 |
| 表情 std | **0.00254** | 中性（所有候选中最低）|

**sample2.jpg（男性, seed 6）**

| 指标 | 值 | 含义 |
|---|---|---|
| yaw | **-6.07°** | 轻微偏头，可用 |
| pitch | **+5.34°** | 轻微俯角，可用 |
| roll | **-0.15°** | 几乎不歪 |
| 表情 std | **0.00775** | 轻微微笑 |
| \|三轴\| 合计 | **11.56°** | **男性候选中最低**（次优 s8 为 11.37°，但表情更重）|

选法说明：男性候选里按"三轴角度合计"排序取最优，`seed 6` 与 `seed 8` 接近，
但 `seed 6` 的表情更平（0.00775 vs 0.00880），所以选了 `seed 6`。

**为什么在意正脸 + 中性**：源图的姿态和表情会被外观特征 `f_s` 一起编码，
**关键点修正去不掉**。所以底图越正、越没表情，后续驱动越自然。

**为什么要求正脸 + 无表情**：源图的表情会被外观特征 `f_s` 一起编码进去，
关键点修正去不掉它。所以底图越中性，后续表情驱动越自然。
